# PoetryOffice Vision

## The Dream

Implement a foundational Document Kit for Haiku os, 
build upon a shared foundation capable of
representing knowledge, ideas, designs, text, diagrams, data and
future document types we cannot yet imagine.

At the center of this vision stands BDocument.

---

## BDocument

BDocument is a versatile reusable C++ implemantation

It is a living, structured document model.

A document is a collection of interconnected objects
that could be enhanced to repersent different Type of documents.

---

## Our Goal

Create a document framework that allows developers to focus on
their domain instead of rebuilding:

- document structures
- undo/redo systems
- document persistence
- serialization
- automation
- extensibility

again and again.

---

## Compound Documents

Documents should be able to contain other documents.

A report may contain spreadsheets.
A spreadsheet may contain charts.
A design document may contain diagrams.
A knowledge base may contain references to other documents.
Everything should compose naturally.

---

## Real-Time Interaction

Documents should feel alive.
Objects can be moved.
Structures can be reorganized.
Layouts can adapt.
The user should feel directly connected to the document and its contents.
so live feedback should be vital.
---

## Extensibility

The framework should welcome new ideas.

New document types should be introduced without changing
the foundation.

Future developers should be able to create completely new
applications on top of the same architecture.

---

## Applications

The framework should be capable of powering:

- Word processors
- Spreadsheets
- Presentations
- Diagram editors
- Knowledge systems
- ProjectConceptor-like applications
- Mind mapping tools
- Engineering tools
- Applications not yet imagined

---

## The Long-Term Vision


PoetryOffice is an ecosystem.
At its core is DocumentKit.

A common foundation where documents become structured,
extensible and reusable building blocks for future software.
