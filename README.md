PoetryOffice Documentation

This repository contains the architectural vision,
design decisions and core concepts behind the
PoetryOffice ecosystem.

The central concept is BDocument, a reusable
document framework intended to support future
applications such as:

- Writer
- Spreadsheet
- Presentation
- Diagram Editors
- ProjectConceptor-like applications
- Future document-based tools

This repository is the single source of truth
for architectural decisions.
